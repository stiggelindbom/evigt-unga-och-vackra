Make: inlägg ut på sociala medier

Görs en gång. Sedan skickar du allt från backoffice → 📣 Inlägg.

1. Före start

  • Instagram måste vara ett Företagskonto (Business) – inte Skapare, för då kan Make inte lägga ut Reels – och kopplat till Facebook-sidan. Gäller både bandets och DJ Stigges konton. (Instagram → Inställningar → Kontotyp och verktyg → Byt till företagskonto.)
  • Make Core (ca 9–11 $/mån) behövs för video: gratisnivån tar bara filer upp till 5 MB. Reels: max 90 s på Facebook.
  • Ha inloggningarna till Facebook, Instagram och YouTube nära till hands (de ligger kanske i 🔐 Valvet).

2. Importera mallen

⬇ Ladda ner mallen
  1. Logga in på make.com → Scenarios → Create a new scenario.
  2. Klicka på ⋯ (längst ner i verktygsraden) → Import Blueprint → välj filen → Save.
  3. Klicka på första blocket Webhooks → Create a webhook → namn Devigtunga inlägg → Save → Copy address to clipboard.
  4. Backoffice → 🔐 Valv & koder → Make-webhook → Lägg in → klistra in.
  5. I Make: klicka Run once. I backoffice: skicka ett testinlägg med en stående video (t.ex. ett klipp från 🎬 Gör video). Make visar då vad som kom in.
Mallen är färdigbyggd: webhooken, fyra vägar (DJ Stigge/bandet × stående/liggande), "Hämta videon/bilden", en växel per kanal med filter för kryssrutorna – och sist ✅ Rapportera till devigtunga som ger den gröna pricken i backoffice. Det enda du lägger till är själva Instagram-, Facebook- och YouTube-blocken (de kräver din inloggning).

3. Lägg till kanalerna

På varje väg finns små "Instagram/Facebook/YouTube – lägg till blocket efter mig" (en kort paus på 1 sekund). Klicka på + till höger om dem och lägg till rätt block:

VägKonton
DJ Stigge · stående/bildInstagram · Facebook · YouTube Shorts – DJ Stigges konton
DJ Stigge · liggandeYouTube · Facebook – DJ Stigges konton
Bandet · stående/bildInstagram · Facebook · YouTube Shorts – bandets konton
Bandet · liggandeYouTube (@devigtunga) · Facebook – bandets konton
Storlekar: stående 9:16 (max ca 90 s) → Reels och Shorts. Liggande 16:9 (hela låtar) → vanlig YouTube- och Facebook-video. Instagram får inga liggande videor. Kampanjinlägg är bilder (omslaget): på Instagram/Facebook-grenarna kan du lägga en liten Router med två vägar – typ = video → Reel/video, typ = bild → foto-inlägg. YouTube tar bara video (filtret sköter det).

✅ Grön prick i backoffice (kvitto)

Sist på varje väg ligger ✅ Rapportera till devigtunga. När alla kanaler har gått bra skickar den ett kvitto till GitHub, och backoffice visar en grön prick per kanal på inlägget. Gör så här en gång:

  1. GitHub → Fine-grained token → namn Make kvitto → Repository access: Only select repositories → evigt-unga-och-vackra → Permissions → Repository → Contents: Read and write → Generate → kopiera.
  2. Lägg den i 🔐 Valvet (+ Ny inloggning → "GitHub-nyckel för Make").
  3. I Make: öppna ✅ Rapportera på varje väg (fyra stycken) → Headers → Authorization → ersätt KLISTRA_IN_GITHUB_NYCKELN_HÄR med nyckeln (behåll Bearer före) → OK.

Prickarna: 🟢 ligger ute · 🟡 väntar på kvitto · 🔴 inget kvitto efter 2 timmar (titta i Make → History vad som gick fel). Går något block fel stoppar Make, och då kommer inget kvitto – så den gröna pricken betyder att allt verkligen gick igenom.

Planerade inlägg

Inlägg du planerar i kalendern skickas av GitHub var 15:e minut. Lägg in webhook-adressen även där – en gång:

  1. GitHub → repot evigt-unga-och-vackra → Settings → Secrets and variables → Actions → New repository secret.
  2. Name: MAKE_WEBHOOK · Secret: webhook-adressen från Make → Add secret.

Instagram Reel

  1. Sök Instagram for Business → Create a Reel Post (eller "Create a Video/Reel Post").
  2. Connection: Add → logga in med Facebook → välj rätt sida och Instagram-konto.
  3. Video URL: media_url (från Webhooks). Caption: text. (Bild: Create a Photo Post med Image URL = media_url.)

Facebook-video

  1. Sök Facebook Pages → Upload a Video (eller "Create a Reel").
  2. Page: välj sidan. File: välj Hämta videon/bilden. Description: text. (Bild: Upload a Photo på samma sätt.)

YouTube

  1. Sök YouTube → Upload a Video. Connection: logga in med Google-kontot för rätt kanal.
  2. File: Hämta videon/bilden.
  3. Title: skriv {{first(split(1.text; newline))}} (första raden i texten). Stående video blir automatiskt en Short – lägg gärna till #Shorts sist.
  4. Description: text, ny rad, lank. Privacy: Public. Category: Music. Made for kids: No.

4. Slå på

  1. Save (diskettikonen) → slå på reglaget Immediately as data arrives / ON nere till vänster.
  2. Klart! Varje gång du trycker Skicka i backoffice läggs inlägget ut automatiskt.
