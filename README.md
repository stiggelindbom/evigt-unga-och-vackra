# De Evigt Unga å Vackra

Hemsida för De Evigt Unga å Vackra. Statisk sida – öppna `index.html` i en webbläsare.

- `index.html` – hela sidan (HTML, CSS, JS)
- `assets/` – logga, omslag och bilder

Låtar, Spotify- och Facebooklänkar ändras i `musik/innehall.js`.
Hur man lägger upp nya låtar: se `musik/LAGG-UPP-LATAR.md`.

Sidan måste köras från en webbserver (t.ex. GitHub Pages eller Freddes server) för att radion ska fungera fullt ut.
